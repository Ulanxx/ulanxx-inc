# AI Native Learning & Blog

> 从 0 到 1 构建 AI Agent 系统，用博客记录成长的每一步。

## 🎯 项目背景

作为一个有 AI Agent 开发经验的技术人员，我需要一个系统化的学习路径来巩固知识体系。碎片化学习能解决短期问题，但难以构建完整的认知框架。因此，我启动了一个 **4周深度开发计划**，聚焦于构建一个功能完整的 **AI 情景演练智能体**。

**核心目标**：
- **体系巩固**：系统学习 LangChain.js、LangGraph、Deep Agents 等现代 AI Agent 开发框架
- **项目驱动**：通过实际开发一个 AI 情景演练智能体，将理论转化为实践
- **深度优先**：专注单一项目的功能深度，而非广度扩展
- **博客沉淀**：每天记录学习过程，形成可追溯、可复用的技术资产

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| **LangChain.js** | AI Agent 开发核心框架 |
| **LangGraph** | 状态机和工作流管理 |
| **OpenAI API** | 大语言模型服务 |
| **Milvus** | 向量数据库，用于语义记忆存储 |
| **TypeScript** | 类型安全，提升代码质量 |

## 💡 思考与沉淀

> 真正的成长不在于你学了多少，而在于你记录了多少、复盘了多少。

这个项目不仅是一个技术实践，更是一次 **刻意练习**。每天 2 小时的投入，1 小时学习输入 + 1 小时编码实践，用输出倒逼输入，用博客沉淀思考。

**为什么选择情景演练智能体？**
- 复杂度适中：既包含基础架构，又涉及多轮对话、状态管理等高级概念
- 实用性高：可用于谈判训练、危机应对模拟、角色扮演教育
- 扩展性强：为未来开发更复杂的多智能体系统打下基础
