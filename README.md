# { Ulanxx Inc } 个人技术站

![Banner](https://img.shields.io/badge/FE-Knowledge-blue) ![License](https://img.shields.io/badge/License-MIT-green) ![VitePress](https://img.shields.io/badge/Framework-VitePress-brightgreen)[![Netlify Status](https://api.netlify.com/api/v1/badges/ab37ecd9-1924-4151-88fa-61bb582010a3/deploy-status)](https://app.netlify.com/sites/ulanxx-inc/deploys)

> 一个基于 VitePress 的个人技术分享与知识积累站点，整合前端面试要点、技术笔记与深度思考。

## ✨ 项目特点

- 🚀 **前端面试速通** - 系统整理前端面试知识点，提供常见问题解答和代码示例
- 📝 **技术笔记分享** - 深入探讨前端技术，包含工程化实践与最佳方案
- 🧠 **技术思考沉淀** - 记录技术思考与探索，提供个人见解和创新思路
- 🎨 **现代化设计** - 基于 VitePress 构建，提供优雅的阅读体验和响应式布局

## 🔍 主要内容

本站内容主要分为三大板块：

### 1. 前端面试速通

系统整理前端面试知识点，包括但不限于：

- 算法与数据结构
- 计算机网络
- JavaScript 核心知识
- 前端框架原理
- 性能优化策略
- 工程化实践

### 2. 技术笔记

分享前端开发中的技术积累，主题包括：

- 现代 CSS 解决方案 (Tailwind、CSS-in-JS)
- 自动化工具探索与实践
- 前端架构设计思路
- 新兴技术应用研究

### 3. 技术思考

记录对技术发展的思考和探索，包括：

- 技术趋势分析
- 开发模式革新
- AI 与前端结合的可能性
- 个人技术成长路径

## 🛠️ 技术栈

- **文档框架**：VitePress
- **主要语言**：Markdown、TypeScript
- **部署平台**：Netlify

## 📦 本地开发

```bash
# 克隆项目
git clone https://github.com/Ulanxx/ulanxx-inc.git

# 安装依赖
yarn install

# 启动开发服务器
yarn docs:dev

# 构建生产版本
yarn docs:build
```

## 📖 目录结构

```
docs/
├── .vitepress/       # VitePress 配置
├── interview/        # 前端面试速通
│   ├── algorithm/    # 算法与数据结构
│   ├── network/      # 计算机网络
│   └── frontend/     # 前端技术
├── blog/             # 技术笔记
│   ├── style/        # 样式解决方案
│   └── automa/       # 自动化工具
└── idea/             # 技术思考
```
